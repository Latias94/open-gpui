# Breaking Change Inventory

This inventory tracks public API moves and deletions that must appear in changelog and GitHub Release notes before publishing the next pre-1.0 breaking stabilization release.

The table is the release-audit index. The [Open GPUI v0.3 UI migration guide](../ui/migration-v0.3.md)
is the canonical downstream walkthrough for lifecycle, callback, identity, and ownership changes.
