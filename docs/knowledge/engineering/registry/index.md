# Work Registry

This directory is for active or recently active producer registrations.

Create one file per branch, worktree, machine, or delegated agent lane when that work may overlap
with another producer. Update only your own registration file, and link to sharded progress,
verification, handoff, or subagent files rather than copying large state into the registration.

`current-state.md` may summarize registrations during an explicit integration pass, but the
registration files here are the source of truth for parallel work.
